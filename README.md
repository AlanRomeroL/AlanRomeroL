## 🚀 Proyectos destacados

### 🛡️ Ciberseguridad

#### [Mini SOC: detección de amenazas con Wazuh](https://github.com/AlanRomeroL/mini-soc-wazuh-threat-detection-lab)

Laboratorio de seguridad defensiva con **Wazuh** para centralizar eventos de un endpoint Linux, analizar intentos de autenticación SSH, generar alertas y comprobar el flujo de detección de un SOC. Incluye pruebas controladas y notificaciones mediante Telegram.

**Tecnologías:** Wazuh · Linux · SSH · VirtualBox · Telegram

#### [Analista de seguridad — Portafolio de ciberseguridad](https://github.com/AlanRomeroL/Analista-de-seguridad)

Repositorio de proyectos y documentación de ciberseguridad, con material sobre auditoría de seguridad y reporte de incidentes.

**Enfoque:** análisis de seguridad · documentación técnica

### 🖥️ Infraestructura, almacenamiento y alta disponibilidad

#### [Almacenamiento replicado con GlusterFS](https://github.com/AlanRomeroL/glusterfs-replicated-storage-lab)

Implementación de un volumen distribuido y replicado entre **dos servidores Ubuntu**. Incluye pruebas de sincronización, tolerancia a fallos y recuperación de datos tras la caída de un nodo.

**Tecnologías:** GlusterFS · Ubuntu Server · Bash · VirtualBox

#### [Alta disponibilidad con Keepalived, VRRP y Nginx](https://github.com/AlanRomeroL/keepalived-vrrp-high-availability)

Configuración de una **IP virtual (VIP)** entre dos servidores Ubuntu para mantener el acceso a un servicio web mediante **failover automático** ante fallos del nodo principal o de Nginx.

**Tecnologías:** Keepalived · VRRP · Nginx · Ubuntu Server · Bash

#### [Replicación y recuperación con PostgreSQL 16](https://github.com/AlanRomeroL/postgresql-replication-lab)

Laboratorio con dos servidores Ubuntu que implementa **streaming replication**, comprueba la sincronización de datos y documenta un **failover manual** con recuperación de la replicación.

**Tecnologías:** PostgreSQL 16 · Ubuntu Server · replicación WAL
